# Support

Software Release Radar is a community-maintained self-hosted project.

## Use GitHub Issues for

- reproducible bugs;
- installation defects;
- documentation errors; and
- focused feature requests.

## Use GitHub Discussions for

- configuration questions;
- deployment patterns;
- integration ideas; and
- general usage help.

## Security issues

Do not use Issues or Discussions for security vulnerabilities. Follow `SECURITY.md`.

There is no guaranteed support response time or service-level agreement.
