# Support

Software Release Radar is a community-oriented self-hosted project maintained as a side project while I’m looking for my next role.

If the project saves you time or is useful in your environment, any support is appreciated and helps me keep developing and maintaining it. Financial support is entirely optional and does not change your rights under the AGPL-3.0 licence.

## Support development

- **Buy Me a Coffee:** https://buymeacoffee.com/muhdusama
- **PayPal:** https://www.paypal.com/paypalme/muhdusama

GitHub also exposes these options through the repository’s Sponsor button using `.github/FUNDING.yml`.

## Use GitHub Issues for

- reproducible bugs;
- installation defects;
- documentation errors; and
- focused feature requests.

## Use GitHub Discussions for

- configuration questions;
- deployment patterns;
- integration ideas; and
- general usage help.

## Security issues

Do not use Issues or Discussions for security vulnerabilities. Follow `SECURITY.md`.

There is no guaranteed support response time or service-level agreement.
