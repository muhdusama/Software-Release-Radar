## About the Codex credit

OpenAI Codex is credited here because it has played a substantial role in building the project.

Codex is an AI coding tool rather than a conventional GitHub contributor account. GitHub's automatic contributor graph is based on commit authorship, so Codex may not appear there as a separate contributor even though its contribution is acknowledged by the project.

The maintainer remains responsible for deciding what is accepted, testing changes in practice, reviewing results and approving releases.
