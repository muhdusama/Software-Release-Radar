## AI-assisted development and maintenance

AI was used to assist in the development and maintenance of Software Release Radar. OpenAI Codex and Anthropic Claude Code have helped with code, debugging, tests, security review assistance, documentation and release preparation.

The maintainer directs the work, reviews proposed changes, verifies behaviour and decides what is accepted and deployed. AI assistance does not replace human responsibility for the software.

This development disclosure is separate from the optional in-app Release Assistant. Core release monitoring, probes, scheduling and standard notifications work without an LLM.

## About contributor attribution

These credits explicitly recognise the people and AI tools involved. GitHub calculates its contributor displays from commit attribution; editing this document alone does not update those displays. New AI-assisted commits can carry an accurate co-author trailer as well as these visible project credits.
